TITLE
JustBlock Security – Ad Blocker, Malware & Phishing Protection

SHORT DESCRIPTION
Block ads, trackers, malware, phishing & scams with MV3 rules. No data collection. Lightweight, fast, easy to use.

DETAILED DESCRIPTION
JustBlock Security is a lightweight Chrome protection extension built for ad blocking, privacy and safer browsing.

It helps block intrusive ads, trackers, phishing pages, scam links, malware risks, risky downloads, crypto-mining scripts, email trackers and optional adult content using Chrome’s Manifest V3 Declarative Net Request engine.

Why install JustBlock?
• Ad blocker: reduce intrusive ads and noisy web pages.
• Tracker protection: block common tracking domains and hidden email pixels.
• Safer browsing: help stop known phishing, scam and unsafe websites.
• Malware and risky download protection: reduce exposure to suspicious destinations and file patterns.
• Crypto miner blocking: stop known in-browser crypto-mining scripts.
• Facebook privacy controls: optional controls for tracking, seen receipts and typing indicators.
• Junk Cleaner: remove common tracking parameters such as utm_source, fbclid, gclid and msclkid.
• Privacy-first design: no analytics, no telemetry and no browsing history collection.
• Local MV3 rules: blocking runs inside Chrome with no remote code.

Built for people who want simple browser protection without heavy antivirus-style bloat.

Privacy & transparency
JustBlock does not collect, transmit or sell personal browsing data. Rules are bundled with the extension and filtering is handled locally by Chrome.
