JustBlock Security 3.0.9

Product-focused polish release.

Changes:
- Smarter context-aware activity messages based on current domain, page type, HTTPS state and URL tracking parameters.
- Removed generic startup-style activity lines from the normal feed.
- Icon badge now shows meaningful state: ON, checking, secure check, attention needed, or OFF.
- Badge tooltip now explains the current protection state instead of showing a fixed number only.
- Kept ethical rating flow and feedback path.

Notes:
- No fake threat counts were added. Activity is based on real local page checks and extension state.
