JustBlock Security 3.1.0

Added Popup Guard in gentle default mode.
- Enabled by default because it blocks only automatic/unwanted popups and pop-unders.
- Allows normal user-click popups for login, OAuth, checkout and payment flows.
- Adds Popup Guard to core shields in the popup UI.
- Logs meaningful activity when a popup is blocked.
- Badge can show P1/P2/P9+ when popups are stopped during the day.
