JustBlock Security 3.0.6

What changed:
- Added visible live protection activity in the popup so users feel the extension is actively protecting them.
- Added pages-checked-today counter, active rule-pack count, and last-check time.
- Added Chrome toolbar badge that shows active protection count, or OFF when paused.
- Added ethical rating flow: asks if JustBlock is helping, sends happy users to Chrome Web Store reviews, sends unhappy users to feedback email.
- Added subtle “Enjoying JustBlock? Rate us” link in the footer.
- Added activity logs for site checks, link cleaning, allowlist actions, toggles, and protection pause/resume.

Important:
- This release does not fake threat counts.
- It does not ask users specifically for 5-star reviews.
- It avoids spammy review prompting and only asks after engagement or explicit user click.
