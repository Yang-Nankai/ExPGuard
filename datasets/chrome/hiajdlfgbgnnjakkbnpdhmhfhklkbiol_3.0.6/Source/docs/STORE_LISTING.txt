TITLE
JustBlock Security – Ad Blocker, Malware & Phishing Protection

SHORT DESCRIPTION
Block ads, trackers, malware, phishing & scams with MV3 rules. No data collection. Lightweight, fast, easy to use.

LONG DESCRIPTION
JustBlock Security gives Chrome a lightweight ad blocker and security layer using Manifest V3 rules. It helps reduce intrusive ads, trackers, phishing pages, scam links, malware risks, risky downloads and crypto-mining scripts — without collecting browsing data.

Why install JustBlock?
• Block intrusive ads and trackers
• Help stop phishing, scam and unsafe websites
• Reduce malware, risky-download and crypto-miner threats
• Email tracker blocking for common hidden tracking pixels
• Optional Facebook privacy controls
• Optional adult-site protection, off by default
• Simple site controls and whitelist
• Manifest V3 rules, no remote code, minimal permissions

Privacy
JustBlock is privacy-first. It does not collect, transmit or sell browsing history or personal data. Filtering runs locally through Chrome’s Manifest V3 Declarative Net Request system.

Built for people who want fast, simple browser protection without heavy antivirus-style bloat.

Notes for Review
No misleading security claims; we avoid absolute guarantees such as “blocks all ads” or “prevents all malware.” The extension operates within Chrome’s Declarative Net Request constraints.
