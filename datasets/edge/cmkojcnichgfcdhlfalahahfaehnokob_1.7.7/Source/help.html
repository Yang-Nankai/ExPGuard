General
Command Remarks
[element text] Mimics clicking an element (e.g. clicking a link). Will set focus to elements with a blue numbered label to enable scrolling. It usually only takes the first two words for elements with multi-word text to run the command. If you can't determine the command text, you can Use the display all labels command as an alternative.
show [element text] Mimics moving the mouse pointer over the element (e.g. to open a drop down menu). Sometimes browser constraints enforced by the site prevent this command from working.
hide [element text] Mimics moving the mouse pointer away from the element that is being hovered over (e.g. to close a drop down menu). Sometimes browser constraints enforced by the website prevent this command from working.
enter key Mimics pressing the enter key. Commonly used to execute a search and can be used as an alternative to the click element command. Sometimes browser constraints enforced by the site prevent this command from working.
escape key Mimics pressing the escape key. command. Sometimes browser constraints enforced by the site prevent this command from working.
focus [element text] Puts focus on the element. This is useful for selecting an element without using the next element or previous element commands. Can also be used in combination with the click element command.
browse * Opens a web page in the current tab (e.g. "browse yahoo.com")
web search * Does a search using the browser's default search engine in the current tab for the term(s) specified (e.g. "web search revolutionary war")
back Mimics clicking the browser's back button.
forward Mimics clicking the browser's forward button.
home page opens the sites home page.
reload Mimics clicking the browser's reload/refresh button.
bookmark page Saves the current page to the "Other Bookmarks" folder.
remove bookmark Removes bookmark from the current page.
open web Opens the Web Assist widget.
minimize web Closes the Web Assist widget and displays the microphone icon.
close web Turns off speech recognition, minimizes the Web Assist widget, and displays the microphone icon.
open notes Opens a simple text editor that you can use for dictation. You can then use the highlight all, copy text, and paste text commands to insert the text into any input related element.
close notes Closes the Notes app.
open help Opens help.
close help Closes help.
click element Clicks the element that currently has focus.
click page Clicks the body of the web page. This can be used pop-up dialogs like menus.
sound effects Plays sound effects after certain events like timeouts. Note, you will need to interact with the page (e.g. press any key or click the page) to use this command.
no sound Turns off sound effects.
display labels Displays numbered labels when they are hidden. This command can also be used to reset labels if they aren't positioned correctly.
hide labels Hides the numbered labels.
display all labels Displays numbered labels for all clickable elements. You may need to use this for some commands because the element's text is hidden.
underline commands Underlines the text associated with each command element (e.g. link). This can be used to help identify the command text.
hide commands Removes the underline from each command element's text.
quiet mode Disables voice activation for the page. This command is useful for when background noise might be an issue.
end quiet mode Enables voice activation after being in quiet mode. You can also reload the page instead.
left side Moves the widget and microphone to left side of the web page.
right side Moves the widget and microphone to right side of the web page.

Command Remarks

end key Moves the cursor to the end of the text.
delete * Mimics pressing the delete key one or more times (e.g. "delete five").

copy text Copies the highlighted text.

Forms
Element Remarks
Text input Use the [element text] command to set focus to the element.
Lists Use the [element text] command to set focus to the element and then say one of the list item values or say move down or move up to pick an item.
Radio button Use the [element text] command to select the option associated with the radio button.
Checkbox Use the [element text] command to check and uncheck the element.
Email input Accepts email addresses. All spaces will be removed and you can say "at" to insert the @ symbol and "dot" to insert a period (e.g. "j wilson at yahoo dot com").
Date input Accepts dates in M D Y format (e.g. "January first two thousand and twelve).
Time input Accepts time values in H (M) am/pm format (e.g. "eleven thirty pm").
Date/Time input Accepts Date/Time values in H (M) am/pm M D Y format (e.g. "January first two thousand and twelve eleven thirty pm).
Number input Accepts integer values (e.g. "twenty").
Password input Accepts any kind of text.
Range slider Accepts integer values. You can also use the move left and move right commands to move the slider left or right.
Search input Accepts any kind of text. See the dictation commands and symbols sections for additional information.
URL input Accepts text in URL format. All spaces will be removed so you won't need to use the spell command to insert individual letters.

Audio Recorder (see for additional commands)
Command Remarks
quality * The quality of the recording. Audio quality can be set to: "medium" (voice notes), "good" (podcasts), or "high" (high quality music). The default is "medium." The actual quality will depend on the quality of the hardware used for recording and playing.

play recording Plays or resumes playing the recording.
stop playing Stops playing the recording and returns the position to the beginning.
pause Pauses playing of the recording
download recording Saves the recording to your computer
close recorder Closes the audio recorder

Tips
For better recognition use Web Assist in a quiet environment with little to no noise.
For better recognition use a plugin, external microphone.
For best dictation recognition, dictate one sentence at a time with a brief pause in between.
If you are unable to use commands to scroll the main page or a section within the main page, use the focus command to move focus to an element within the part of the page you want to scroll.
If you are unsure of the command text to use or the command is not being recognized, use the display all labels command.
Use the spell command while dictating to add text not recognized by Web Assist.
If for some reason a command is not working, try using the focus command to set focus to a nearby command element. Then use the the next element or previous element commands and click element command to navigate to and click the element.
If a numbered command is not being recognized, say each number in the command one at a time (e.g. 10 - "1" + "0")
If you are dictating a message, make sure you know what you want to say ahead of time to avoid hesitations, which can affect recognition.
If you can't use an element's scrollbar because there is no label, use the focus command to focus an element that is contained within the scrollable container.
If the microphone icon is covering an element, use the left side command to reposition the microphone icon and the right side command to return it back to its default position.
