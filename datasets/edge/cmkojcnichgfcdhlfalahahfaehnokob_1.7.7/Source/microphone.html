Thank you for installing Web Assist 1.7.7!

Instructions: To get started simply click on the red microphone icon (if needed) in the bottom-right corner to activate the voice recognition feature. Please note that you'll need to allow the extension access to your microphone when using it for the first time. The exception is Facebook, where you'll have to grant permission on your first visit. Existing tabs will need to be reloaded manually to load the newest version of the extension.

In this update, an issue with the extension sometimes not detecting network errors was fixed. You can also check out our demos to explore some of the most commonly used voice commands.

EDGE USERS: Edge's built-in voice dictation feature automatically inserts basic punctuation (commas, periods, and question marks) as you speak to multi-line input elements. However, to add other punctuation or symbols (e.g. dollar sign), you'll need to pause dictating first. You will also need to dictate in sentence form (one or more) to make sure the text is properly punctuated.

Be aware that this extension and other extensions that use speech to text will be disabled when browsing the Edge and Chrome stores.
