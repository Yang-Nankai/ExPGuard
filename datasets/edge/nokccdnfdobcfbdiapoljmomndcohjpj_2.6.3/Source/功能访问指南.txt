一、隐藏功能访问步骤

1. 深度搜索功能
访问路径：扩展选项页面 → 高级设置
功能描述：启用后可以捕获更多隐藏的媒体资源
访问步骤：
  1) 右键点击扩展图标 → 选择"选项"
  2) 滚动到页面底部找到"深度搜索"选项
  3) 勾选启用深度搜索
  4) 刷新目标网页以激活功能

2. 正则表达式匹配
访问路径：扩展选项页面 → 正则表达式
功能描述：自定义URL匹配规则，支持复杂模式匹配
访问步骤：
  1) 进入选项页面
  2) 找到"正则表达式"部分
  3) 点击"添加正则表达式"
  4) 输入匹配模式和文件扩展名
  5) 设置是否为黑名单模式

3. 自定义请求头设置
访问路径：扩展选项页面 → 高级设置
功能描述：修改HTTP请求头以绕过某些限制
访问步骤：
  1) 在选项页面找到"自定义User-Agent"
  2) 输入自定义的User-Agent字符串
  3) 保存设置后重启扩展

4. 侧边栏模式
访问路径：扩展选项页面 → 界面设置
功能描述：在浏览器侧边栏中显示资源列表
访问步骤：
  1) 启用"侧边栏"选项
  2) 在浏览器侧边栏中打开扩展
  3) 需要Chrome 114+版本支持

二、高级设置和配置

1. 文件类型过滤
配置位置：js/init.js 中的 G.OptionLists.Ext 和 G.OptionLists.Type
默认支持格式：
  视频：mp4, webm, mkv, avi, mov, flv, f4v, m4s, ts
  音频：mp3, wav, m4a, aac, ogg, opus
  流媒体：m3u8, m3u, mpd
自定义步骤：
  1) 在选项页面添加新的文件扩展名
  2) 设置最小文件大小限制
  3) 启用/禁用特定格式

2. 下载器集成
支持的下载器：
  Aria2 RPC：需要本地运行Aria2服务
  奇妙下载器：内置下载功能
  外部调用：支持调用系统默认下载器

3. 媒体播放器集成
支持的播放器：
  PotPlayer
  VLC
  MX Player (Android)
  系统默认播放器

三、条件性功能

1. 版本相关功能
Chrome 93+：基础功能
Chrome 101+：完整功能支持
Chrome 114+：侧边栏功能
Firefox 113+：完整功能支持

2. 平台相关功能
移动端限制：
  默认禁用后台下载
  简化界面显示
  限制最大缓存数量（999 vs 9999）

桌面端优势：
  完整功能支持
  更大的缓存容量
  更多高级选项

3. 权限相关功能
必需权限：
  tabs：标签页访问
  webRequest：网络请求拦截
  downloads：下载管理
  storage：数据存储
  scripting：脚本注入

可选权限：
  sidePanel：侧边栏功能
  declarativeNetRequest：网络请求修改

四、外部依赖关系

1. 第三方库依赖
核心依赖：
  hls.js (lib/hls.min.js)：HLS流媒体解析
  jQuery (lib/jquery.min.js)：DOM操作
  mux.js (lib/mux.min.js)：MP4解析
  mpd-parser (lib/mpd-parser.min.js)：MPD文件解析
  StreamSaver.js (lib/StreamSaver.js)：流式下载

可选依赖：
  jquery.json-viewer (lib/jquery.json-viewer.js)：JSON预览
  jquery.qrcode.min.js (lib/jquery.qrcode.min.js)：二维码生成
  base64.js (lib/base64.js)：Base64编码

2. 外部服务依赖
在线服务：
  FFmpeg在线服务：用于视频转码
    主服务：https://ffmpeg.bmmmd.com/
    备用服务：https://ffmpeg2.bmmmd.com/
  用户文档：https://cat-catch.bmmmd.com/

本地服务：
  Aria2 RPC：默认地址 http://localhost:6800/jsonrpc
  本地HTTP服务：用于数据发送功能

3. 浏览器API依赖
Chrome扩展API：
  chrome.webRequest：网络请求拦截
  chrome.downloads：下载管理
  chrome.storage：数据存储
  chrome.tabs：标签页管理
  chrome.scripting：脚本注入

Web API：
  fetch：网络请求
  Blob：二进制数据处理
  MediaRecorder：媒体录制
  WebRTC：屏幕录制

五、扩展限制和注意事项

1. 功能限制
Service Worker限制：
  5分钟后自动终止，需要心跳机制保持活跃
  无法直接访问DOM
  内存使用限制

网络请求限制：
  某些网站的反爬虫机制
  CORS跨域限制
  请求频率限制

2. 兼容性限制
浏览器版本要求：
  Chrome 93+ (Manifest V3)
  Firefox 113+ (部分功能)
  Edge 93+ (基于Chromium)

移动端限制：
  功能简化
  性能限制
  界面适配

3. 安全限制
权限使用：
  需要访问所有网站权限
  网络请求拦截权限
  下载管理权限

数据隐私：
  所有数据本地存储
  不向远程服务器发送数据
  无跟踪器

4. 性能限制
内存使用：
  最大缓存数量限制
  自动清理机制
  重复检测功能

CPU使用：
  正则表达式匹配限制
  文件类型检测优化
  预览生成限制

六、故障排除

1. 常见问题
扩展不工作：
  1) 检查浏览器版本兼容性
  2) 确认所有权限已授予
  3) 重启扩展和浏览器

无法捕获资源：
  1) 检查文件类型过滤设置
  2) 确认目标网站未被屏蔽
  3) 尝试启用深度搜索

下载失败：
  1) 检查下载器配置
  2) 确认网络连接正常
  3) 验证文件URL有效性

2. 调试方法
开发者工具：
  1) 打开扩展的开发者工具
  2) 查看Console日志
  3) 检查Network面板

扩展调试：
  1) 在扩展管理页面启用开发者模式
  2) 查看扩展的错误日志
  3) 使用扩展的调试功能
