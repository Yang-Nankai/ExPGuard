# 📑Introduction
MagicalDownloader is a resource detection extension that helps you filter and list resources from the current page.
This project is modified from https://github.com/xifangczy/cat-catch

# 📘Installation Methods
## Store Installation
Install through the official extension store via the installation links above.
## Source Code Installation
1. Git clone the code.
2. Open "Developer mode" on the extension management page.
3. Click "Load unpacked" and select the extension folder.
## crx Installation
1. Download the crx file from [Releases](https://github.com/9292922/MagicalDownloader/releases) by **right-click and save as**.
2. Open "Developer mode" on the extension management page.
3. Drag the crx file into the extensions page.

# 📚Compatibility Notes
Versions after 1.0.17 require Chromium kernel version 93 or above.
For versions below 93, please use version 1.0.16.
For full functionality experience, please use version 104 or above.
