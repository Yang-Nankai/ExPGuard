# Security Vulnerability Report: High Extension Storage Poisoning in Cursor Trails - Custom Cursor Trails

## Summary

We are writing on behalf of a security research team from Nankai University and the University of Liverpool. Our Ground Truth review identified **3 Flow(s)** in **Cursor Trails - Custom Cursor Trails** (chrome, extension ID `ilngnjopnchkedjkdjlalnlbfpkhmbie`, version `4.4.14`).
The recorded issue type(s): **Extension Storage Poisoning**.

The store currently reports version `4.6.41`. The update revalidation is summarized per tool below. This report covers only the original Flow(s); newly introduced Flow(s) are out of scope. Any mixed result, tool failure, or incomplete automated run is called out explicitly and should not be read as a final remediation determination.

The Ground Truth record traces An external extension able to message this extension from `CHROME_ONMESSAGEEXTERNAL_MESSAGE` (chrome.runtime.onMessageExternal.addListener[message]) in background at L1:C10832 -> L1:C10833 to the privileged sink `CHROME_LOCAL_STORAGE` (animationType) in background at L1:C14843 -> L1:C15087. ## Recommendations

1. Do not let page-controlled cookies or DOM values select extension-owned storage values; validate the expected value and keep credentials in extension-owned UI/state.
2. Treat storage writes as privileged state changes: use an allowlisted schema, reject attacker-controlled keys, and avoid merging untrusted objects into extension state.
3. Reduce host permissions and sensitive API access to the smallest scope required by the feature.

## Impact

The demonstrated impact is limited to the operation described in each finding and the extension's granted permissions. The evidence above distinguishes the recorded static path from any runtime result; it does not imply unrelated account compromise, data theft, or malware installation.
