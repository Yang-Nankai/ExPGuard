# Output format

ExPGuard writes the following files into the `--out` directory:

```
<out>/
  ├─ analysis.log          ← winston log, level = config.logLevel
  ├─ manifest.json         ← copied from the unpacked extension (always retained)
  ├─ report.txt            ← human-readable per-file taint report
  ├─ summary.json          ← machine-readable global summary
  └─ unpacked/             ← extracted extension (retention = config.artifactRetentionPolicy)
```

## `report.txt`

Generated by `printTaintReportsCLI(taintManager.generateGlobalReport())` in `src/taint/report.ts`.

```
══════════════════════════════════════════════
TAINT REPORT  content
FRAME        CS_1
CONSTRAINT   {"matches":["<all_urls>"]}
══════════════════════════════════════════════

[!] Issue #1
 ├─ Source     : WINDOW_MESSAGE_EVENT
 ├─ Remark     : window.addEventListener(message)
 │  Location   : L3:C20 -> L3:C35
 │  File       : content
 │  Frame      : CS_1
 │  Constraint : {"matches":["<all_urls>"]}
 │
 ├─ Propagation:
 │   ELEMENT    @ L3:C20 -> L3:C35 (member-element)
 │   ASSIGN     @ L3:C20 -> L3:C35 (binary-left)
 │   ...
 │   (total steps: 12)
 │
 ├─ Sink(s):
 │   - CHROME_LOCAL_STORAGE @ L5:C4 -> L7:C6 (title)  [file: content]
 │     frame: CS_1
 │     constraint: {"matches":["<all_urls>"]}
 │
 └─ Sanitized : NO

Summary:
  File            : content
  Issues          : 1
══════════════════════════════════════════════
```

Truncation is governed by `config.taintReportOptions`:

- `level = "detailed"` — print every propagation step (up to `maxFlowPerIssue`)
- `level = "partial"` — keep `headCount` + `tailCount` plus an explicit `...(N steps omitted)` marker
- `level = "brief"` — first + last step only

The whole structure is also accessible programmatically through `taintManager.generateGlobalReport(opts)`. Each per-file object:

```
{
  filename: "content",
  fileFrame: "CS_1",
  fileFrameConstraint: { matches: ["<all_urls>"] },
  fileFrames: [ { id: "CS_1", family: "CS", constraint: { ... } } ],
  totalIssues: 1,
  issues: [
    {
      source: {
        kind: "WINDOW_MESSAGE_EVENT",
        remark: "window.addEventListener(message)",
        loc: "L3:C20 -> L3:C35",
        file: "content",
        frame: "CS_1",
        frameConstraint: ...,
        frames: [ ... ],
        code: "... >>>event.data<<< ..."   // when includeCode is true
      },
      flow: [
        { kind: "ELEMENT", loc: "L3:...", remark: "member-element", code: ">>>...<<<" },
        ...
      ],
      flowMeta: { totalSteps: 12, omitted: 0 },
      sinks: [
        {
          kind: "CHROME_LOCAL_STORAGE",
          remark: "title",
          urlTaintControl: undefined,
          loc: "L5:C4 -> L7:C6",
          file: "content",
          frame: "CS_1",
          frameConstraint: ...,
          frames: [ ... ],
          code: ">>>...<<<"
        }
      ],
      sanitized: false
    }
  ]
}
```

`PSEUDO_*` sources never appear here — they only exist for cross-context resolution.

## `analysis.log`

Plain text from `src/utils/logger.ts` (winston). Levels: `debug` < `info` < `warn` < `error`. Useful tags:

- `[SCRIPT-USAGE]` — frame propagation decisions
- `[CONTEXT]` — `analyzeScriptsInOrder` progress
- `[EPG]` / `[EPG DONE]` — top-level analyzer status
- `[TAINT-SINK]` — every sink hit (debug level)
- `[TAINT-SANITIZER]` — sanitizer applications

## Retention

`config.artifactRetentionPolicy` controls what survives after `cleanupArtifacts`:

- `"none"` — wipe everything except `alwaysRetainedArtifacts` (default: `summary.json`)
- `"keep_if_sink"` — keep `unpacked/`, `report.txt`, and `analysis.log` only if at least one flow was detected
- `"all"` — keep everything

Defaults: `"none"` + retain `summary.json` — production runs ship only metadata unless explicitly opted into keeping artifacts.
